# Grégoire — Portfolio

Portfolio personnel construit avec React, Vite et CSS.

## Projets présentés

- [CloudVisionF](https://github.com/gregoiremrcr/cloudvisionF)
- [IoT / MQTT](https://github.com/gregoiremrcr/iot-mqtt)

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir l'URL affichée par Vite.

## Build

```bash
npm run build
npm run preview
```

## Personnalisation

Les projets et leurs contenus sont regroupés dans `src/main.jsx`.
Le style complet est dans `src/styles.css`.
