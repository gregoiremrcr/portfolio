ROBOTIQUE · AUTONOMIE

Robotique

Robotique est un prototype de robot d’assistance autonome conçu pour permettre à un opérateur de créer une mission, de la suivre en temps réel et de superviser l’exécution d’une tâche complète : navigation, reconnaissance QR, prise d’objet, transport puis dépose.

React TypeScript PHP MySQL ROS 2 WebSocket Docker

Contexte

Le projet vise à démontrer une chaîne logicielle complète autour d’un robot logistique : interface web pour piloter des missions, API backend pour gérer les données, échanges temps réel, et robot autonome piloté par ROS 2.

Objectif

Créer un système cohérent dans lequel une mission peut être planifiée, affectée au robot, exécuter la navigation, identifier un objet grâce au QR, effectuer la prise puis finaliser le dépôt en sécurité.

Fonctionnalités principales

  • Dashboard React/TypeScript pour créer, consulter et supprimer des missions.
  • Gestion des statuts et transitions de mission via une logique claire et supervisable.
  • Suivi temps réel des événements, erreurs, position et état du robot.
  • Mission complète en mode simulation puis en mode réel avec navigation, lecture QR, prise, transport et dépose.
  • Arrêt d’urgence logiciel et vérification de sécurité avec timeout heartbeat.

Architecture

Le dépôt est structuré autour de trois éléments majeurs : le frontend web, une API REST PHP/MySQL, et un environnement ROS 2 pour le robot. Le WebSocket permet de synchroniser l’état des missions et d’afficher les événements en direct depuis le dashboard. Cette séparation permet de garder une logique claire entre interface, orchestration métier et partie robotique.

Résultat

Le système a été validé avec des tests intégrés et une exécution complète du workflow, notamment en mode faux robot puis sur le robot réel. Le projet montre un vrai parcours d’intégration complexe : interface, backend, communication temps réel, robotique autonome, vision et automatisation.
